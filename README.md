# Portfólio pessoal — Kayque Silva

Projeto acadêmico da atividade de Fundamentos da Programação Web (UNINTER).

## Tecnologias
- HTML5
- CSS3 puro (sem frameworks)
- JavaScript puro (sem bibliotecas)

## Como visualizar
Abra o arquivo `index.html` em um navegador ou utilize a extensão Live Server no Visual Studio Code.

## Funcionalidades
- Navegação por âncoras entre as quatro seções obrigatórias.
- Layout responsivo para computador e celular.
- Menu móvel.
- Alternância entre tema claro e escuro.
- Validação de nome, e-mail e mensagem com JavaScript.
- Simulação de envio do formulário (não envia dados para servidor).
